# Security & Governance

这是跨 Skill / Expert / Connector / Buddy App / Open API / Hardware 的统一安全治理层。

官方第三方应用模型明确存在：

- Resource Owner
- Third Application
- WorkBuddy
- Open Platform

用户数据访问必须经过显式授权，Scope 应遵循最小权限原则。

官方来源：

- https://open.workbuddy.cn/docs/third-party-app
- https://open.workbuddy.cn/docs/openapi

本目录同时包含 OFFICIAL 事实与 DERIVED 工程控制；每份文档会明确标记。
