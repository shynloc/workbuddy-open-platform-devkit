# Qualification & Service Categories

WorkBuddy 开放平台在发布前要求开发者先完成主体认证，并根据实际服务能力选择服务类目。个人主体与非个人主体可选类目、资质要求并不完全相同。

官方来源：

- 个人主体：https://open.workbuddy.cn/docs/service-categories-individual
- 非个人主体：https://open.workbuddy.cn/docs/service-categories-enterprise
- 入驻：https://open.workbuddy.cn/docs/onboarding

## 本目录解决什么问题

不要等到“包已经做完”才发现主体或资质不匹配。

开发流程应在 Requirement Intake 之后增加：

```text
Publisher Entity
→ Actual Service
→ Service Category
→ Qualification Required?
→ Eligible / Adjust Scope / Stop
```
