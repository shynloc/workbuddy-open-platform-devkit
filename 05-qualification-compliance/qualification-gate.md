# Qualification Gate

提交任何 WorkBuddy 产品前执行。

## Publisher

- [ ] 已确认个人 / 非个人主体
- [ ] 主体认证已完成
- [ ] 市场展示主体名称与实际发布主体一致

## Actual Service

- [ ] 已按真实功能描述产品，不按营销名称判断
- [ ] 已列出所有用户可见核心服务
- [ ] 已识别公开传播、交易、医疗、法律、金融、教育、文娱等高监管功能

## Category

- [ ] 已打开当前官方类目页
- [ ] 已选最匹配实际服务的类目
- [ ] 多能力产品已确认是否需要多个类目
- [ ] 已记录核验日期

## Qualification

- [ ] 官方要求的证件/许可/备案/合作协议已具备
- [ ] 资质主体与发布主体/业务关系匹配
- [ ] 审核材料已脱敏并由授权人员保管

## Stop Conditions

任何一项成立时暂停提交：

- 实际功能明显超出可选类目；
- 官方要求资质但当前不具备；
- 不确定应选哪个受监管类目；
- 试图靠修改文案绕过真实服务范围。
