# 个人主体

官方来源：https://open.workbuddy.cn/docs/service-categories-individual

个人主体可选服务能力相对受限。官方当前页面列出了各二级/三级类目、资质要求、适用范围和备注。

几个能帮助 Agent 理解边界的当前示例：

- 教育信息展示：只适用于教育信息展示，不支持教育视频播放/直播、课程产品销售等扩展能力；
- 物流查件：不包含寄件、收件业务；
- 备忘录：适用于待办记录，不涉及用户原创内容传播和公开访问；
- 律师：需要对应律师执业资格；
- 企业管理、公关/推广/市场调查、摄影/扩印等当前存在可用个人类目。

## 工程规则

1. 不把此页摘要当完整白名单；
2. 任何新产品提交前重新打开官方类目页；
3. 如果产品包含多个实际服务，逐项确认，而不是只挑一个最宽泛的类目；
4. 资质要求为“/”只表示该类目当前表格未列额外资质，不代表免除其他法律/平台责任。
