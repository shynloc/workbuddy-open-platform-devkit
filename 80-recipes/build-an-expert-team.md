# Recipe: 从复杂任务到 Expert Team

1. 确认任务真的需要多角色；
2. 先画任务拓扑：Pipeline / Parallel / Debate / Review Gate；
3. 定义 Lead；
4. 每个 Member 定义 Input / Specialty / Output；
5. 删除职责高度重叠成员；
6. 建 plugin.json 的 teamInfo / members；
7. 建 settings.json 指定 Lead；
8. 建各 Agent MD；
9. 把共享方法放 skills/；
10. 按需声明 MCP / Connector dependencies；
11. 为团队和所有成员准备头像；
12. 测试 Lead 是否真正拆解/汇总，而不是自己全做；
13. 测试成员失败、信息冲突、部分结果缺失时的恢复。
