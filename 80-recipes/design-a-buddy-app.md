# Recipe: 设计 Buddy App

1. 定义行业和目标用户；
2. 先列 ≥5 个高频场景；
3. 把场景聚类为 2–4 个工作模式；
4. 给每个模式定义 System Prompt + Skill；
5. 选择首页场景胶囊；
6. 策展应用内 Market：Experts / Skills / Connectors；
7. 决定是否内置 OAuth MCP Connector；
8. 选择模型组合、排序、默认模型；
9. 准备 icon / scene backgrounds；
10. 完成五个配置模块；
11. 导出配置备份；
12. 用官方 preview 链接 + 对应客户端测试；
13. 提交配置审核；
14. 如面向企业，规划企业单与授权模式。
