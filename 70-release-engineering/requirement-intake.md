# Requirement Intake

开始做 WorkBuddy 资产前回答：

## Product

- 用户是谁？
- 用户想完成什么结果？
- 高频还是一次性？
- 核心价值在“方法、角色、团队、外部系统、行业工作台、外部应用”哪一层？
- 最小可用版本是什么？

## Data / Integration

- 是否需要用户私有数据？
- 是否需要第三方 API / MCP / CLI？
- 身份认证如何完成？
- 哪些操作有外部副作用？
- 哪些操作必须二次确认？

## Distribution

- 公开市场还是企业分发？
- 个人主体还是企业主体？
- 是否涉及额外服务类目/资质？
- 需要哪些 icon / avatar / 背景资产？

## Done

输出一份 Product Brief，并明确：

```text
Product Type
Target User
Core JTBD
Inputs
Outputs
Dependencies
Risks
Release Target
Definition of Done
```
