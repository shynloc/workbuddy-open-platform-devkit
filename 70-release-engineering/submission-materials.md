# Submission Materials

提交前准备至少三类信息：

## 1. 产品信息

- 名称
- 中英文描述
- 版本
- 作者/主体
- 分类/标签
- 典型使用示例

## 2. 视觉资产

依产品类型：

- Skill 市场 icon（以当前开放平台上传位要求为准）
- Expert / Team avatar：官方要求 512×512、≤500KB
- Connector icon：SVG 推荐；PNG/JPG 官方建议 64×64
- Buddy App icon / avatar / featured-scene backgrounds：按对应配置位规范

## 3. 审核说明

建议准备：

- 产品解决什么问题
- 用户操作路径
- 为什么需要对应权限/Scope
- 外部数据如何使用
- 高风险操作如何确认
- 隐私/凭据如何存储
- 测试账号或测试方法（若平台要求）

不要在审核说明中包含真实生产 Secret。
