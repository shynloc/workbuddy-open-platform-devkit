# Release Engineering

所有 WorkBuddy 生态资产共用的发布工程层。

建议统一流程：

```text
Requirement Intake
→ Product Type Decision
→ Product Brief / PRD
→ Architecture
→ Build
→ Local Validation
→ Runtime Test
→ Release Materials
→ Packaging
→ Submission QA
→ Platform Review
→ Review Fix
→ Publish
→ Version & Operations
```

- requirement-intake.md

- submission-materials.md
