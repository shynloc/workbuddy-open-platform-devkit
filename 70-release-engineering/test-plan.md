# Runtime Test Plan

每个 WorkBuddy 生态资产至少测试以下维度。

## Happy Path

- [ ] 首次使用
- [ ] 重复使用
- [ ] 跨会话继续
- [ ] 典型大输入

## Error Path

- [ ] 缺参数
- [ ] 参数格式错误
- [ ] 网络失败
- [ ] 超时
- [ ] 权限不足
- [ ] 认证过期
- [ ] 外部服务返回错误

## Compatibility

- [ ] 当前最低支持 WorkBuddy 版本
- [ ] 当前稳定版本
- [ ] macOS / Windows（如涉及本地能力）
- [ ] 中文 / 英文展示字段（如提供）

## Safety

- [ ] 删除/发布/发送/支付等确认
- [ ] Secret 不出现在日志
- [ ] 最小权限
- [ ] 多用户数据隔离

## UX

- [ ] 用户从市场安装/召唤后知道下一步
- [ ] 错误信息可恢复
- [ ] 没有依赖时有清晰引导/fallback
