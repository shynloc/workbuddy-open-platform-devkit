# Skill Publishing Checklist

- [ ] ZIP 顶层只有一个 Skill 根目录
- [ ] 根目录存在 SKILL.md
- [ ] YAML frontmatter 可解析
- [ ] 必填字段齐全
- [ ] version 为 SemVer
- [ ] description 足以帮助模型识别触发场景
- [ ] `@references/...` 全部存在
- [ ] scripts 命令在 Bash 环境可执行
- [ ] templates 路径存在
- [ ] 无绝对本地路径
- [ ] 无 Secret / Token / Key
- [ ] ZIP 不含缓存与隐藏垃圾文件
- [ ] 已用自然语言测试触发与误触发
- [ ] 如依赖外部能力，有 fallback 或明确依赖说明
- [ ] 市场 icon 满足当前开放平台上传位要求
- [ ] 提交当天重新核验官方 Skill 文档
