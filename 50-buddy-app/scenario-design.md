# 场景胶囊设计

官方强调场景优先。场景胶囊不是“功能目录”，而是帮助用户以结果导向启动任务。

## 好场景的条件

- 高频；
- 用户能理解结果；
- 用户不一定知道怎么写 Prompt；
- 可以映射到一个稳定的 Mode / Expert / Skill；
- 能明显缩短首次启动成本。

## 场景模板

```text
Scene Name:
User Intent:
Example Prompt:
Work Mode:
Expert/Team:
Skill:
Connector:
Expected Output:
Success Signal:
```

## 反例

- “打开 AI”
- “开始工作”
- “万能助手”
- 仅按内部组织架构命名的场景

这些不能帮助用户快速获得结果。
