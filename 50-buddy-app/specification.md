# Buddy App 官方规范

官方来源：https://open.workbuddy.cn/docs/buddy-app

## 1. 定位

官方将 Buddy 应用定义为垂直行业 AI Harness：伙伴不必从零构建完整 AI 产品，而是把行业 know-how、专业数据与已有系统装进 WorkBuddy 底座。

核心强调：

- 行业 Harness
- 开箱即用
- 场景优先

## 2. 六大自定义维度

官方当前描述的能力包括：

- 工作模式：System Prompt + 内置 Skill
- 场景胶囊：推荐场景 + 可绑定 Expert/Skill/案例
- 模型配置
- 垂直行业市场：Skills / Experts / Connectors / 灵感案例
- 内嵌已有功能：如 MCP Apps
- 以及与上述能力配套的应用级配置

## 3. WorkBuddy 提供的底座

官方说明包括：

- 多 Agent 协同
- 上下文压缩
- 记忆工程
- 工具调用编排
- 安全与权限

## 4. 5 个配置模块

1. 创建应用
2. 首页配置
3. 市场配置
4. 其他配置
5. 预览调试

应用创建后生成 Client ID / Client Secret，Client Secret 只完整展示一次。
