# Post-release Operations

官方开放平台生命周期并不止于“审核通过”。官方概述明确包括上线后持续监控运行数据和维护版本。

官方来源：

https://open.workbuddy.cn/docs/what-is-open-platform

本目录把发布后的工作工程化：

- `post-release.md`
- `versioning-and-compatibility.md`
- `rollback-and-incident.md`
- `deprecation.md`
- `support-handoff.md`

生命周期：

```text
Publish
→ Observe
→ Support
→ Patch / Upgrade
→ Compatibility Review
→ Incident / Rollback
→ Deprecate / Replace
```
