# Templates

这里存放可复用工程模板。**禁止写入真实 Secret、Token、AppSecret 或用户数据。**

## 当前模板

- `product-brief.md`
- `source-metadata.md`
- `release-handoff.md`
- `submission-checklist.md`
- `skill-template/`
- `expert-template/`
- `expert-team-template/`
- `connector-template/`
- `buddy-app-template/`

模板的目标是提供结构起点，不替代官方最新字段规范。

使用前：

1. 阅读对应模块的 specification；
2. 核验官方来源；
3. 复制模板；
4. 按当前产品填写；
5. 执行对应 QA。
