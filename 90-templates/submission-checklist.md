# Submission Checklist

## Publisher / Qualification

- [ ] 发布主体正确
- [ ] 主体认证完成
- [ ] 官方服务类目已重新核验
- [ ] 必需资质/许可证/备案/合作协议已具备

## Product / Package

- [ ] 产品类型选择正确
- [ ] 官方规范在提交当天重新核验
- [ ] 包结构/平台配置完整
- [ ] 所有路径、字段、版本可解析
- [ ] 视觉资产尺寸/体积满足当前上传位
- [ ] 中英文展示文案完整
- [ ] 示例是真实用户语言

## Security / Data

- [ ] 无 Secret/Token/私有数据
- [ ] 认证失效路径已测
- [ ] 权限/Scope 最小化
- [ ] 高风险外部操作有确认
- [ ] 多用户数据/凭据隔离
- [ ] 日志脱敏
- [ ] 数据保留/删除策略明确

## Validation

- [ ] Local Validator / Schema 通过
- [ ] Runtime Test 完成或明确标记未运行
- [ ] Validation Record 已创建
- [ ] 审核说明准备完成
- [ ] 记录提交版本与日期

## Operations

- [ ] 上一个稳定版本/回滚方式已知
- [ ] 发布后负责人明确
- [ ] 支持/故障升级路径明确
- [ ] 兼容性/依赖版本已记录
